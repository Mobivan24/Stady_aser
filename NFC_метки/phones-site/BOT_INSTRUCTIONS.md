# Инструкция для бота: сайт «Телефоны дома» и NFC-метки

Документ для помощника, который работает с этим проектом. Пользователь — владелец дома и сети. Все действия, которые пишут на NAS, меняют конфиг агента или перезаписывают метку, выполняет и подтверждает пользователь.

Корень проекта на ПК: `D:\Programing\NFC_метки\`. Пути ниже указаны от него.

## 2. Как работает страница

- Страница строится из Excel целиком. Данные встроены в HTML, внешних запросов нет.
- Колонки из Excel: `Объекты` (направление), `Кто занимается` (имя), `Связь` (номера, e-mail, мессенджеры), `Примечание` (комментарий). Колонка `№№` не выгружается.
- Примечание выводится оранжевым текстом под контактом. Если пусто, блока нет.
- Номер `+380…` нормализуется. Нестандартные номера остаются как есть и попадают в отчёт сборки.
- Ссылка `…/phones/phones.html#Направление` открывает фильтр по направлению.
- Страница открывается только из домашней сети или через VPN. Web Publishing NAS отдаёт её без входа любому устройству в домашней сети, поэтому гостей держать в гостевой сети роутера.

## 3. Как обновить данные

0. Закрыть `Телефоны.xlsx` в Excel (открытый файл может быть заблокирован или содержать несохранённые правки).
1. Пользователь правит `Телефоны.xlsx` и сохраняет его.
2. Пользователь запускает сборку через командную строку:
   ```
   cd /d "D:\Programing\NFC_метки\phones-site"
   chcp 65001
   set PYTHONIOENCODING=utf-8
   python build_phones.py > "%TEMP%\phones_run.txt" 2>&1
   echo EXIT=%errorlevel%
   ```
   Двойной щелчок по `build_phones.bat` может закрыть окно до вывода ошибки, поэтому предпочтителен запуск из cmd.
3. Проверить `EXIT=0` и строку «Опубликовано: …» в выводе или в `%TEMP%\phones_run.txt`.
4. Попросить пользователя обновить страницу (Ctrl+F5 на ПК, обновление в браузере на телефоне).

Если выводится «Нет модуля openpyxl»: `python -m pip install openpyxl`. Если «Файл не найден»: проверить доступ к `\\192.168.1.103\Dom`.

Проверка без записи: `python build_phones.py --dry-run` или `--out <локальная папка>`.

## 4. Что бот делает сам, а что только через подтверждение

Можно без подтверждения:
- читать эту инструкцию, `phones.config.json`, `build.log`, шаблон;
- запускать `--dry-run` и `--out <временная папка>`;
- читать журнал агента и `allowed-tags.json`;
- проверять страницу по HTTP (только чтение). Облачный помощник без доступа к сети 192.168.1.x этого не может: проверку делает пользователь (`curl -I <адрес>` или скриншот) и присылает результат.

Только после явного «да» пользователя:
- публикация на NAS (`build_phones.py` без параметров);
- правка `allowed-tags.json`, `settings.json` (перед правкой — копия `*.bak`);
- любое действие, которое пишет в `\\192.168.1.103\NFC-Hub`.

Не делать никогда:
- редактировать опубликованный `phones.html` вручную (он перезаписывается);
- выкладывать номера телефонов в публичные места, чаты, GitHub, если пользователь не просил;
- записывать UID личных меток в репозиторий (они хранятся в `allowed-tags.json` и реестре меток);
- записывать секреты, пароли, токены в URL или в конфиги.

## 5. Метки NFC (ACR122U)

Агент только читает метки. Записывать URL на метку должен пользователь с помощью NFC-приложения на телефоне (например, NFC Tools), тип «URL/URI».

Подходящие метки: только NTAG213 (обычные наклейки; «для металла» — только на металл). Карты и брелоки Fudan 1K (клон MIFARE Classic) не подходят: iPhone и многие Android не читают с них NDEF-ссылку.

Адрес для метки телефонов: `http://192.168.1.103:5000/MyWeb/NFC-Hub/phones/phones.html`

Порядок подключения новой метки:
1. Страница уже опубликована. Без неё метку не записывать.
2. Пользователь записывает URL на пустую NTAG213: NFC Tools → «Запись» → «Добавить запись» → «URL/URI». В поле префикса выбрать `http://`, в основное поле вставить адрес БЕЗ `http://`. По умолчанию префикс `https://` — частая причина ошибки «URL не совпадает». Затем «Записать».
3. Проверить на вкладке «Чтение»: «Запись 1 — URI» с точным адресом.
4. Узнать полный UID метки. Предпочтительно: NFC Tools, поле «Серийный номер» на вкладке «Чтение» (7 байт, начинается с `04`). Альтернатива: временно `"logFullUid": true` в `settings.json` (только с подтверждением, потом вернуть `false`). Агент в журнал пишет только последние 4 байта UID, для точного совпадения нужен полный. В правило UID записывать заглавными буквами через двоеточие.
5. Добавить запись в `nfc-url-agent\config\allowed-tags.json` (бот предлагает текст, пользователь подтверждает; перед правкой `copy allowed-tags.json allowed-tags.json.bak`). Пример:
   ```json
   {
     "id": "phones-home",
     "name": "Телефоны дома",
     "enabled": true,
     "uid": "XX:XX:XX:XX:XX:XX:XX",
     "allowedUrls": ["http://192.168.1.103:5000/MyWeb/NFC-Hub/phones/phones.html"],
     "action": "open_browser",
     "browser": "default",
     "requireConfirmation": true,
     "notes": "NTAG213, страница телефонов",
     "createdAt": "<фактическое время>",
     "updatedAt": "<фактическое время>"
   }
   ```
   `allowedUrlPrefixes` (например, `…/phones.html#`) добавлять только для меток по направлениям и только после проверки кодирования.
6. Проверить: `npm run validate-config` в `nfc-url-agent`.
7. Агент перечитает конфиг сам (`configWatch`, в журнале «Конфигурация перезагружена успешно»), либо нажать `r` в окне агента.
8. Запустить агент: `start-agent.bat` (он сам проверяет конфиг). Агент должен работать на ПК с подключённым ридером.
9. Тест на ПК: тап метки, окно «Открыть / Отмена», открытие страницы. Результат виден в журнале агента (`confirmed_opened`):
   ```
   cd /d "D:\Programing\NFC_метки\nfc-url-agent"
   findstr /i "phones-home confirmed_opened" logs\nfc-agent-ГГГГ-ММ-ДД.log
   ```
10. Тест на телефоне в домашнем Wi-Fi (телефон читает метку сам, без агента).
11. Внести метку в реестр. Наклеивать после обоих тестов; блокировать запись (lock) — только после нескольких дней без сбоев.

Правила безопасности для меток:
- `requireConfirmation` оставлять `true` для всех меток.
- `uid: null` не использовать для чувствительных ссылок: правило сработает на любую метку с этим URL.
- Только `https:` или `http:` для адресов в локальной сети. Внешние `http://` запрещены.
- Не добавлять в URL пароли, токены, логины.
- Для метки с направлением (`#Электрика`) при записи кириллица кодируется в процентах (около 6 байт на букву). Сначала проверить, что страница открывает нужное направление и как агент сравнивает закодированный URL.

Совпадение хвостов UID: у разных меток последние 4 байта могут совпадать (так уже есть у PHONES и TEST-02). Агент сравнивает полный UID, поэтому правила не путаются, но по журналу метку надо определять по `id` правила, а не по хвосту UID. При тестах можно временно выключить лишнее правило (`enabled: false`).

Типичные проблемы (сообщения агента):
- Тап ничего не делает: агент не запущен или ридер не подключён. Смотреть окно агента.
- «Метка не внесена в таблицу допуска»: неверный UID или правило выключено (`enabled: false`).
- «Метка обнаружена, но разрешённая NDEF URL-запись не найдена»: на метку не записан URL (метка пустая) или запись не типа URI (например, «Текст»). Проверить вкладку «Чтение» в NFC Tools и записать URL.
- «URL не совпадает с разрешённым правилом»: URL на метке отличается от `allowedUrls` или префикса. Чаще всего — `https://` вместо `http://` (префикс NFC Tools по умолчанию) или задвоенный `https://http://`, также лишний `/` в конце, нет `:5000`, опечатка. Сравнить посимвольно с `findstr /n "phones.html" config\allowed-tags.json`.
- Открывается 404: страница не опубликована или папка `phones` удалена.
- Страница не открывается на телефоне: телефон вне домашней сети, нужен VPN.

## 6. Чего бот не делает

- Не пишет на NFC-метки (агент это не умеет и не должен).
- Не меняет права доступа на NAS и сетевые шары.
- Не меняет настройки роутера, NAS, Windows.
- Не публикует страницу сам, если пользователь не подтвердил.
- Не решает за пользователя, звонить ли по контакту: это поле «Примечание», его заполняет пользователь.

## 7. Что сообщить пользователю после действия

- Что изменено (файл, строка или правило).
- Результат проверки (`EXIT=`, HTTP-код, запись в журнале).
- Что ещё нужно сделать пользователю (обновить страницу, записать метку, включить агент).
